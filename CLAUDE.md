## Главное правило проекта

Преподаватель оценивает требования и дизайн отдельно от кода, и прямо говорит:
«Не нужно реализовывать все требования!». Поэтому порядок обратный привычному:

```
требование в docs/requirements/  →  ADR с отклонёнными альтернативами  →  тест  →  код
```

Код без требования-родителя не пишем. Требований должно быть больше, чем кода.

## Среда

Решено 09.09.2026: **Dockerfile как эталонная среда + GitHub Actions как арбитр.**
Это закрывает два пункта критериев сразу — «CI/CD» и «проект должен запускаться в
другом окружении». Самодельный скрипт сборки через `wsl.exe` удалён как костыль.

Файлы среды (`Dockerfile`, workflow, `CMakeLists.txt`) появятся вместе с темой проекта —
раньше им нечего описывать.

ставим, иначе получится второй агент с пустой памятью — см. `feedback_wsl_single_claude`.
