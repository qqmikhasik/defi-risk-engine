# se-project

Проект курса «Технологии в финансах» (мехмат МГУ, осень 2026/2027).
Имя временное — тема не выбрана.

Преподаватель оценивает требования и архитектурный выбор отдельно от кода, поэтому
порядок работы здесь обратный привычному: требование → архитектурное решение → тест → код.

- Требования — `docs/requirements/`
- Архитектурные решения и отклонённые альтернативы — `docs/adr/`

Сборка и запуск описываются в `Dockerfile` и проверяются CI — появятся вместе с темой.
